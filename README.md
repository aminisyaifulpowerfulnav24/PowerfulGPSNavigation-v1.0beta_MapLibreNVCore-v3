This Powerful GPS Navigation app for Android has been revised 3 times, in part to lock the screen orientation while recalculating the route in the condition of real-time navigation route (not a simulated route).**

**This Powerful GPS Navigation v1.0-beta_MapLibreNVCore-3_revision-3 app for Android features are already listed**

**including:**
1.  🗺️🧭🆗 Display maps and MapButtonUI
2.  🔍🗺️🧭 Search geocode by Nominatim server
3. 📍🗺️🧭ℹ️  Display location info on the map after clicking location search results (including get place info and get directions button)
4. 🚗🛣️ℹ️ Route summary after clicking a Get Directions button (including play demo navigation route and start navigation route)
5. 🧭🚗🗺️ turn-by-turn navigation UI (including view route on map and cancel navigation route)
6. The time interval to recalculate the route after going off-route is about 3-4 seconds to give time for adjustments of the arrow heading GPS to avoid sudden recalculation of the route

**not including:**
1. display menu dashboard UI and menu features include manage maps, vehicle profile, SOS, and map and navigation settings
2. click on map to get location info on map
3. click a start place name or end place route waypoint name to change that address even though route waypoints are available
4. Click to change transport mode, even though car and walking modes are available
5. Route options
6. Click the banner " Upcoming Instructions " to view the instructions summary, even though the Upcoming Instructions banner is available for turn-by-turn navigation UI

**Fitur-fitur aplikasi Powerful GPS Navigation v1.0-beta_MapLibreNVCore-v3_revision-3 untuk Android ini sudah tercantum**

**termasuk:**
1.  🗺️🧭🆗 Menampilkan peta dan MapButtonUI
2.  🔍🗺️🧭 Mencari geokode melalui server Nominatim
3. 📍🗺️🧭ℹ️  Menampilkan informasi lokasi di peta setelah mengklik hasil pencarian lokasi (termasuk tombol “Dapatkan Info Lokasi” dan “Dapatkan Petunjuk Arah”)
4. 🚗🛣️ℹ️ Ringkasan rute setelah mengklik tombol “Dapatkan Petunjuk Arah” (termasuk memutar demo rute navigasi dan memulai rute navigasi)
5. 🧭🚗🗺️ Antarmuka navigasi langkah demi langkah (termasuk melihat rute di peta dan membatalkan rute navigasi)
6. Interval waktu untuk menghitung ulang rute setelah keluar dari rute adalah sekitar 3-4 detik guna memberikan waktu bagi penyesuaian arah panah GPS agar terhindar dari perhitungan ulang rute yang mendadak

**tidak termasuk:**
1. Tampilan antarmuka dasbor menu dan fitur menu yang mencakup kelola peta, profil kendaraan, SOS, serta pengaturan peta dan navigasi
2. mengklik peta untuk mendapatkan informasi lokasi di peta
3. mengklik nama tempat awal atau nama titik perhentian rute tujuan untuk mengubah alamat tersebut meskipun titik perhentian rute sudah tersedia
4. mengklik untuk mengubah moda transportasi, meskipun mode mobil dan berjalan kaki sudah tersedia
5. opsi rute
6. mengklik spanduk “Petunjuk Selanjutnya” untuk melihat ringkasan petunjuk, meskipun spanduk Petunjuk Selanjutnya sudah tersedia untuk antarmuka navigasi langkah demi langkah
